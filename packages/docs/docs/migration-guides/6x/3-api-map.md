# Every legacy call and what replaces it

Search this page for the name that your code uses. Each name has a row in the
table of its group. The row gives the call to use in 6.0.

**State.** The calls in the column "Use instead" are in the code, on the next
viewports. A row that says **Decided, not in the code yet** is about the
removal: the legacy classes, types, settings and helpers that it names are
still in the code, and the viewport types still have their `_NEXT` names. See
[Next viewports only](./1-next-viewports-only.md).

## How to read a row

- **Legacy** is the name in 5.x.
- **6.0** says what happens to the name:
  - **Same name**: the next viewport of that family has the member and it
    means the same. Where the meaning or a default differs, the last column
    starts with "Differs".
  - **Replaced**: the name is gone. Another call does the job.
  - **Removed**: the name is gone and no call takes its place. The row says
    why, and what to do.
- **Use instead** is the call, as code. `viewport` is a next viewport.
  `displaySetId` is the id that the application registered, see
  [A display set is registered once](./1-next-viewports-only.md#a-display-set-is-registered-once).
- **What it does** says in one line what the call does.
- **Access** is **Public** for a member of the viewport, an event, or a name
  exported from `@cornerstonejs/core` or `@cornerstonejs/tools`. It is
  **Private** for a name inside the library that an application cannot
  import.
- **Stack and volume, notes**: a planar viewport shows a stack of 2D images
  or a volume. `viewport.getCurrentMode()` is `'stack'` or `'volume'`. The
  column says what the call does in each mode.

`utilities`, `cache`, `viewportProjection`, `eventTarget` and `Enums` are
those of `@cornerstonejs/core`, unless the row names the tools.

## Types that still describe a legacy viewport

**In the code today.** The class of every next family is a
`Types.IGenericViewport`, and a function of the library that works on a next
viewport takes `Types.IViewport | Types.IGenericViewport`. So the calls of
this page compile as written in TypeScript, with no cast. Two places are
still typed for a legacy viewport. In this table `viewport` is typed as
`PlanarViewport`.

| Call                                                                                         | What TypeScript says                                                                                                      | Write                                                                                                                                                  | Why                                                                                            |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `viewport.getResolvedView()?.toICamera()`                                                    | The result is a `PlanarResolvedICamera`, which is not a `Types.ICamera`                                                   | Type the variable as `PlanarResolvedICamera`, or read the keys that you need from the result                                                           | The `scale` of a planar camera is a pair, for a stretched view. `Types.ICamera` has one number |
| `getEnabledElement(element).viewport`, and each viewport of `renderingEngine.getViewports()` | The type is a legacy one: `Types.IStackViewport \| Types.IVolumeViewport` for the first, `Types.IViewport` for the second | Narrow with `utilities.isGenericViewport(viewport)`, or ask for the viewport with its class: `renderingEngine.getViewport<PlanarViewport>(viewportId)` | The tools still read legacy members from these types                                           |

A function that reads members of the planar family takes the class beside
the legacy type: `utilities.getClosestStackImageIndexForPoint(point, viewport)`
and `utilities.getCurrentVolumeViewportSlice(viewport)` take a
`PlanarViewport`. A variable of the type `Types.IGenericViewport` does not
fit them, because a 3D viewport has no slice. Type the variable with the
class.
