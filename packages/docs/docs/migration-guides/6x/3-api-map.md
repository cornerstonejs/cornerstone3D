# Every legacy call and what replaces it

Search this page for the name that your code uses. Each name has a row in the
table of its group. The row gives the call to use in 6.0.

**State.** The calls in the column "Use instead" are in the code, on the next
viewports, and so is the removal: on 6.0 the legacy classes, types, settings
and helpers that the rows name are gone. See
[Next viewports only](./1-next-viewports-only.md).

## How to read a row

- **Legacy** is the name in 5.x.
- **6.0** says what happens to the name:
  - **Same name**: the next viewport of that family has the member and it
    means the same. Where the meaning or a default differs, the last column
    starts with "Differs".
  - **Replaced**: the name is gone. Another call does the job.
  - **Removed**: the name is gone and no call takes its place. The row says
    why, and what to do.
  - **Deprecated**: the name still works in 6.x and means the same as the
    name in "Use instead". Move to that name.
- **Use instead** is the call, as code. `viewport` is a next viewport.
  `displaySetId` is the id that the application registered, see
  [A display set is registered once](./1-next-viewports-only.md#a-display-set-is-registered-once).
- **What it does** says in one line what the call does.
- **Access** is **Public** for a member of the viewport, an event, or a name
  exported from `@cornerstonejs/core` or `@cornerstonejs/tools`. It is
  **Private** for a name inside the library that an application cannot
  import.
- **Stack and volume, notes**: a planar viewport shows a stack of 2D images
  or a volume. `viewport.getCurrentMode()` is `'stack'` or `'volume'`. The
  column says what the call does in each mode.

`utilities`, `cache`, `viewportProjection`, `eventTarget` and `Enums` are
those of `@cornerstonejs/core`, unless the row names the tools.

## Viewport types

The plain names are in the code, in `Enums.ViewportType` and
`Enums.ViewportTypes`: `PLANAR` (`'planar'`), `VOLUME_3D` (`'volume3d'`),
`VIDEO` (`'video'`), `WHOLE_SLIDE` (`'wholeSlide'`) and `ECG` (`'ecg'`). Each
gives the viewport of its family, and that string is its `viewport.type`.

## The type of a viewport in 6.0

**In the code.** `Types.IViewport` is the interface of a viewport of any
family: planar, 3D, video, whole slide or ECG. It has the members that every
family has, those of the base class `GenericViewport`. The class of each
family fits it, so a `PlanarViewport` goes where the library takes a
`Types.IViewport`, with no cast. `Types.IGenericViewport` is the same
interface under its deprecated 5.x name. In this table `viewport` is typed
as `Types.IViewport`.

| Call                                                                                                                                | What TypeScript says                                                                           | Write                                                                                                                                                                                                                                                                                                                                                                        | Why                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `getEnabledElement(element).viewport`, `renderingEngine.getViewport(viewportId)`, each viewport of `renderingEngine.getViewports()` | A `Types.IViewport`. A member of a family, such as `viewport.getCurrentImageId()`, is an error | Ask for the class: `renderingEngine.getViewport<PlanarViewport>(viewportId)`. Or narrow: `utilities.viewportSupportsDisplaySetPresentation(viewport)` for a planar viewport, `utilities.viewportSupportsImageSlices(viewport)` for `getCurrentImageId`, `getCurrentImageIdIndex` and `getImageIds`. Code that only runs on one family can cast: `viewport as PlanarViewport` | The viewport can be of any family. In 5.x the enabled element typed it as a stack or volume viewport, also when it was a 3D or a video viewport |
| `viewport.canvas`, `viewport.getRenderer()`, `viewport.getActors()`, `viewport.getImageData()`, `viewport.getDefaultActor()`        | Not members of `Types.IViewport`                                                               | Type the viewport with its class: `PlanarViewport`, `VolumeViewport3D`, or both for code that runs on either                                                                                                                                                                                                                                                                 | Each family has its own; the rendering engine keeps its own fields of a viewport out of the public interface                                    |
| `viewport.getResolvedView()?.toICamera()` on a `PlanarViewport`                                                                     | The result is a `PlanarResolvedICamera`, which is not a `Types.ICamera`                        | Type the variable as `PlanarResolvedICamera`, or read the keys that you need from the result                                                                                                                                                                                                                                                                                 | The `scale` of a planar camera is a pair, for a stretched view. `Types.ICamera` has one number                                                  |

`utilities.getClosestStackImageIndexForPoint(point, viewport)`,
`utilities.getCurrentVolumeViewportSlice(viewport)`,
`utilities.calculateViewportsSpatialRegistration(viewport1, viewport2)`,
`utilities.getViewportImageCornersInWorld(viewport)` and

`utilities.math.polyline.getSubPixelSpacingAndXYDirections`,

`utilities.planar.getPointInLineOfSightWithCriteria` of the tools.
`utilities.draw3D.addLine3DBetweenPoints` takes a `PlanarViewport` or a
`VolumeViewport3D`. A variable of the type `Types.IViewport` does not
fit them, because a 3D viewport has no slice. Type the variable with the
class.
